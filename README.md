# Quriv Technologies Corporate Website

A modern, high-performance corporate website for Quriv Technologies, a software engineering company specializing in enterprise-grade web applications, cloud infrastructure, and digital transformation solutions.

## Overview

This website showcases Quriv Technologies' expertise in software architecture, featuring interactive 3D backgrounds, multilingual support (English and Arabic), and comprehensive service demonstrations across various industries including hospitality, e-commerce, food industry, and fintech.

## Features

- Modern React-based architecture with TypeScript
- 3D animated background using Three.js
- Full internationalization support (English/Arabic) with RTL/LTR switching
- Responsive design optimized for all screen sizes
- Interactive service showcases with detailed feature demonstrations
- Contact forms and meeting booking functionality
- Professional dark theme with gold accent styling
- Optimized performance with lazy loading and code splitting

## Technology Stack

- React 18 with TypeScript
- Three.js for 3D graphics
- Tailwind CSS for styling
- Framer Motion for animations
- Custom internationalization system
- Vite for build tooling

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn package manager

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser to http://localhost:5173

### Building for Production

```bash
npm run build
```

The optimized production build will be created in the `dist` directory.

## Project Structure

- `src/components` - React components for different sections
- `src/locales` - Translation files for internationalization
- `src/utils` - Utility functions including i18n system
- `src/data` - Static data for services and content
- `public` - Static assets including images and logo
